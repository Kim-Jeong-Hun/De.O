# De.O

최저가 비교 앱 — 같은 상품의 가격을 여러 쇼핑몰에서 가져와 같은 조건으로 비교하는 서비스입니다.

## 프로젝트 개요

**목표:** 카테고리 1개, 상품 30~50개를 대상으로 두 쇼핑몰의 가격을 비교하는 MVP를 약 12주 내 출시

**핵심 기능:** 상품 검색, 가격 비교, 관심 상품 저장, 가격 추이 차트, 목표 가격 알림

**팀 구성:** 2인, 각자 주 15~20시간 작업

## 기술 스택

| 영역 | 기술 | 역할 |
|---|---|---|
| 모바일 앱 | React Native + Expo | 검색, 가격 비교, 관심 상품, 차트, 알림 |
| 백엔드 API | Express | 모바일 API, 요청 검증, 가격 비교 로직 |
| 크롤러 | Python | 별도 Worker 프로세스에서 쇼핑몰별 데이터 수집 |
| 데이터베이스 | MySQL | 상품, 가격 이력, 알림 데이터 저장 |
| ORM | Prisma | DB 스키마 및 마이그레이션 관리 |
| 소개 웹사이트 | Next.js | 앱 설명, 기능 소개, 다운로드 링크 |
| 모노레포 관리 | pnpm workspace + Turborepo | 앱/API/랜딩/공유 패키지 관리 |

## 디렉터리 구조

```
apps/mobile     Expo 모바일 앱
apps/api        Express API 서버
apps/crawler    Python 크롤러 · Worker
apps/landing    Next.js 소개 페이지
packages/db     Prisma 스키마 및 DB 설정
packages/shared 모바일-API 공통 계약
```

## 마일스톤 (총 12주 + 출시 후 1주 검증)

| 단계 | 기간 | 목표 |
|---|---|---|
| M1 | 1주차 | 서비스 범위 확정 |
| M2 | 2주차 | 데이터 확보 검증 (핵심 통과 지점) |
| M3 | 3주차 | 모노레포 · 기본 연결 구축 |
| M4 | 4~5주차 | 가격 비교 기반 완성 |
| M5 | 6~7주차 | 핵심 모바일 기능 완성 |
| M6 | 8주차 | 알림 · 수익화 완성 |
| M7 | 9~10주차 | 비공개 테스트 · 랜딩 제작 |
| M8 | 11~12주차 | 심사 · 출시 |
| M9 | 출시 후 1주 | 초기 운영 검증 |

자세한 계획은 `docs/최저가비교앱_개발_마일스톤.md` 문서를 참고하세요.

## 역할 분담

**A:** 데이터 제공처 조사, Python 크롤러, Express API, Prisma · MySQL, 서버 알림

**B:** Expo 화면 · 검색 · 관심 상품 · 차트, Next.js 소개 페이지, 기기별 테스트 · 스토어 제출

공동: 공통 계약, 인증 · 저장 경로 · 배포 결정, 사용자 테스트, 운영 장애 대응
